# 冻结ProtT5两组对照

两组为冻结ProtT5+六标签分类头+BCE和Masked-BCE。数据为来源并集v3，使用36,000条训练、2,000条验证；测试集不评价。

共享已审阅的训练循环；编码器全部参数requires_grad=False，并固定eval模式。只有LayerNorm、Linear(1024,256)、GELU、Dropout(0.1)、Linear(256,6)分类头更新。无LoRA模块。

种子42、5轮、head_lr=0.0003、weight_decay=0.01、5% warmup、有效batch64。该batch依据历史四卡、每卡microbatch1、累积16配置，不与后续batch16的Mask重复实验混为同一预算。

当前安全GPU均被占用。02运行BCE等待器，03运行Masked-BCE等待器，每600秒检查一次。仅选择无计算进程、显存低于100MiB、利用率不高于5%、ECC=0的GPU；02:2始终排除。显存空余不视作空闲卡。

空闲后取可用的最大1/2/4/8卡组合，保持有效batch64，防止卡数改变训练预算。任务启动后卡数不变。每节点单独文件锁避免重复启动；异常退出保留日志，不盲目重启。

训练未启动前状态为waiting_for_unoccupied_gpu。等待器存在不代表模型已训练。GPU节点共享目录：/sddn/yyf_work/chenzhenghang/mars-tool/experiments/prott5_frozen_pair_20260913_002449。
